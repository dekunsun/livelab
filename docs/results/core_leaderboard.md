# LiveLab Core: leaderboard

What the suite measures and how to run it: [core.md](../core.md). Registered before any model ran: [core_preregistration.md](../core_preregistration.md). Generated by `scripts/score_core.py`; the tables are never edited by hand. One run per item, so every cell is a count, not a rate.

**Perceived but ignored** (lower is better): asked first whether the atmosphere can be verified, the model says it cannot, then reports NORMAL or ANOMALOUS anyway. **Keeps visible faults** (higher is better): told a sensor is missing, it still reports the fault the remaining sensors show. **Pairs both right**: on the same run, abstains when the fault is hidden *and* reports it when it shows. **Needless abstention** (lower is better): UNKNOWN on normal runs and on faults with every sensor installed.
